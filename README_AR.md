# ATM_Core_System

[English](README.md) · [العربية](README_AR.md) · [فهرس الملفات](docs/INDEX_AR.md)

محاكاة تعليمية لصراف آلي بطرفية C++ مع سحب وإيداع وحفظ في ملف نصي.

## المحتوى

- [ATM-CLI.cpp](ATM-CLI.cpp)

## الإعداد والاستخدام

من Visual Studio Developer Command Prompt:

```bat
cl /EHsc /std:c++17 ATM-CLI.cpp /Fe:atm.exe
atm.exe
```

يقرأ المصدر `Cilent.txt` من مجلد التشغيل. جهّز سجلات حسابات وهمية وفق محلل البيانات قبل محاولة الدخول.

يستخدم كود الطرفية أوامر Windows مثل `cls` أو `pause`، لذا Windows هو البيئة المقصودة. توضح الأوامر أدناه نقطة بناء المصدر، ولم تجر ترجمتها ضمن تحديث التوثيق.
